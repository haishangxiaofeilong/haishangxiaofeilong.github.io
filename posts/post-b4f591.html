一开始我把删除顺序全枚举了一遍，然后发现完全没必要

2026-08-30 2673 字— 次阅读

今天刷到 LeetCode 2091 这道题：

一开始差点去枚举所有可能的删除顺序，越想越乱。

其实想清楚一个约束就通了：

因为只能从两头删，删完之后剩下的元素，一定是原数组里一整段连续的部分。

先把规则翻译成人话

只能头删或者尾删，每次动一个元素。

目标是把最大值和最小值都干掉。

求的是最少删几次。

举个通俗点的例子：

想象一排座位，你只能从最左边或者最右边赶人走。

现在要赶走个子最矮和最高的两个人，怎么赶最省事？

你肯定不会从中间抽人，而是从两边把其他人先请走，留下中间一截。

答案只和两个下标有关

设最小值的下标是 left，最大值的下标是 right，约定 left 比 right 小，数组长度记成 n。

因为只能从两头删，最后留下来的必然是一段连续的子数组。

我们要删除的又是最小值和最大值，所以这段连续子数组不能包含下标 left 和 right。

把最值的位置标出来，原数组被分成三个不包含最值的位置区间：

  • 左侧：下标 0 到 left-1
  • 中间：下标 left+1 到 right-1
  • 右侧：下标 right+1 到 n-1

留下的连续子数组可以落在这些区域里的任意一部分。

但删除次数最少等价于留下的元素尽可能多。

同一个区域里，保留得越长，需要删除的元素就越少，所以每个区域只需要考虑“整段保留”的情况。

因此，最优方案只需要在下面三种里取删除次数最少的一种：

  • 保住左侧整段
  • 保住中段
  • 保住右侧整段

三种保留方案，算一笔账

保留哪一段，删除次数就是"总长度减去这段的长度"：

保留哪段 删除方式 删除次数
左段 [0..left-1] 从 left 开始一路删到末尾 n - left
中段 [left+1..right-1] 左边删掉 left+1 个，右边删掉 n-right 个 left + 1 + n - right
右段 [right+1..n-1] 从 0 删到 right right + 1

这三个数里取最小的，就是答案。

拿例子走一遍

nums = [2, 10, 7, 5, 4, 1, 8, 6]，长度 n = 8。

最小值是 1，在位置 5；

最大值是 10，在位置 1。

所以 left = 1，right = 5。

套上面的公式：

  • 保留左段：n - left = 8 - 1 = 7
  • 保留中段：left + 1 + n - right = 1 + 1 + 8 - 5 = 5
  • 保留右段：right + 1 = 5 + 1 = 6

最小是 5。

说人话就是：

从前面删掉 2 个（2、10，把最大值带走），从后面删掉 3 个（6、8、1，把最小值带走），一共 5 次，剩下的就是 [7, 5, 4]。

再看第二个例子，nums = [0, -4, 19, 1, 8, -2, -3, 5]，n = 8。

最小 -4 在位置 1，最大 19 在位置 2，left = 1，right = 2。

三种方案分别需要 7、8、3 次，答案是 3——从前面删 3 个，把 -4 和 19 一次性带走。

代码

逻辑就三步：

找最值下标、定 left 和 right、取三种情况的最小值。

class Solution {
    public int minimumDeletions(int[] nums) {
        int n = nums.length;
        // 一趟遍历，记下最小值和最大值的下标
        int minIdx = 0, maxIdx = 0;
        for (int i = 0; i < n; i++) {
            if (nums[i] < nums[minIdx]) minIdx = i;
            if (nums[i] > nums[maxIdx]) maxIdx = i;
        }

        // left 是两个最值里靠左的下标，right 是靠右的
        int left = Math.min(minIdx, maxIdx);
        int right = Math.max(minIdx, maxIdx);

        // 三种保留方案里，删除次数最小的那个就是答案
        return Math.min(Math.min(right + 1, n - left), left + 1 + n - right);
    }
}

复杂度

时间上，找最值扫一遍数组 O(n)，后面都是 O(1)，整体 O(n)。

空间上，只用了几个变量，O(1)。

小结

这道题的突破口就一句话：

只能从两头删，所以剩下的必然是连续段。

把最值下标 left、right 找到，最终留下的连续子数组不能包含这两个最值，而删除次数最少等于留下元素最多，所以只需比较左、中、右三个完整区域，取删除次数最小的那个，一趟 O(n) 扫完就出来。

别去枚举删除顺序，那只会越想越乱。
